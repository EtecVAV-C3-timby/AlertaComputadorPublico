# Alerta de Computador Público
**Projeto desenvolvido para a aula de IPSSI _(Internet, Protocolos e Segurança de Sistemas da Informação)_.**<br>**EtecVAV, 3ºC 2025**<br><br>
O programa foi desenvolvido em <code>C#</code> usando a tecnologia <code>.NET 8.0</code>. Ele usa do sistema de notificações dos computadores Windows 10+ para alertar o usuário a cada 10 minutos sobre os perigos de computadores públicos.<br>
Ao **executar o software**, ele se **auto-instalará** na máquina no <code>%AppData%</code> e se configurará no registro para ser **iniciado junto com o Windows.**<br>
Quando o usuário clicar na notificação, ele será levado para um [site do governo](https://www.gov.br/fundaj/pt-br/centrais-de-conteudo/noticias-1/12-seguranca-de-computadores) que fala sobre os perigos de computadores/internets públicas.<br>
