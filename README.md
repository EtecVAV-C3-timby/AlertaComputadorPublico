# Alerta de Computador Público
### Projeto desenvolvido para a aula de IPSSI _(Internet, Protocolos e Segurança de Sistemas da Informação)_.
**EtecVAV, 3ºC 2025**
<br>
O programa foi desenvolvido em C# usando a tecnologia .NET 8.0. Ele usa do sistema de notificações dos computadores Windows 10+ para alertar o usuário a cada 10 minutos sobre os perigos de computadores públicos.<br><br>
Ao executar o software, ele se auto-instalará na máquina no %AppData% e se configurará no registro para ser iniciado junto com o Windows.<br><br>
